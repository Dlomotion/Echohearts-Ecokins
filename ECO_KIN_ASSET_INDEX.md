**Project:** Echohearts: Rebearth

**Rule:** One stable specimen ID per Eco-Kin. Never reuse an ID or canonical display name for another specimen.

## Standardized archival convention

`EKIN-####_<CANON-NAME>_<FORM>_<ART-STATE>_v###`

Examples:
- `EKIN-0002_NATURE_BASE_ACTIVE_CANON_ART_v001.png`
- `EKIN-0041_POYZIN-IVVEE_BASE_PENDING_CANON_REVIEW_v001.png`

Forms use controlled labels such as `BASE`, `EVOLUTION`, `MUTATION`, `SHIMMER`, and `HEX`. `HEX` means the hidden variant and does not replace the Base form.

## Visual benchmark rules

Every approved image must visibly distinguish the specimen through all of the following: silhouette, species DNA, body plan, material language, elemental VFX, facial identity, habitat, signature prop/ability cue, and scale language. Rebearth landscape context is required for primary key art.

### Card-image text rule
Each benchmark image must contain only clean archival text: `ECO-KIN’S`, the exact canonical display name, optional form label, and optional Dex ID. No lore paragraph should be baked into the image.

### Existing-art preservation
When an older approved image is located, preserve it under its stable specimen ID and increment the version only for an intentional revision. Do not generate a replacement merely because a new conversation started.

### Variant rule
`SHIMMER` and `HEX` are forms, not new species. They must preserve the original species/DNA, body plan, silhouette family, element identity, ecology, and role. Variant art gets a new form filename but keeps the same stable specimen ID.
