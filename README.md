# Echohearts: Rebearth — ECO-KIN’S Visual Archive

This repository is the visual/archive companion for the existing **Echohearts: Rebearth** project. It does **not** create a second canon, second Dex, or parallel workflow.

## Source-of-truth rule
- Gameplay, lore, systems, IDs, validation, and implementation remain governed by the existing Echohearts: Rebearth master workflow and canonical repository.
- This repository stores Eco-Kin visual references, archival naming records, and approved art benchmarks.
- New or revised specimens must pass: **Rename Audit → Canon Review → Dex Validation → Art Manifest Review → Systems Integration → QA Lock**.
- Never reuse an existing Eco-Kin name, image, silhouette, ecology, element/family role, habitat, signature ability, or evolution identity for a different specimen.
- Existing approved art must be preserved; revisions are versioned instead of silently replaced.

## Art status
Use these states only:
- `ACTIVE_CANON_ART` — approved canonical visual reference.
- `PENDING_CANON_REVIEW` — usable benchmark awaiting final approval.
- `REFERENCE_RETIRED_NEEDS_REDESIGN` — retained for provenance but not current canon.

See `ECO_KIN_ASSET_INDEX.md` for the standardized specimen registry and image-path conventions.
